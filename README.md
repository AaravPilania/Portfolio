# Aarav Pilania — Creative Developer Portfolio

> Studio-grade interactive creative developer portfolio featuring living canvas vector animation, WebGL graphics, physical simulation, and editorial typography.

## Features

- **Living 2D Vector Avatar Engine**: Pure Canvas 2D vector linework with natural skin tones, optical cornea light tracking, and organic line-boil. Zero raster image dependencies.
- **Physical Lens Centerpiece**: 3D extruded marker tube spectacles with dynamic lighting, mouse orientation physics, and authentic handwritten ink reveal shader.
- **Interactive Stack Wheel & Matter.js Stickers**: Interactive canvas wheel and draggable physics stickers powered by Matter.js.
- **Precision Typography & Dual-Layer Motion**: Synchronized clipped marquees and Robert Borghesi / Lama Lama boutique motion standards.
- **High-Performance Architecture**: Hardware tier detection, adaptive DPR clamping (1.0–1.5), and automatic viewport sleep cycles for smooth 60/120fps rendering on everything from Chromebooks to high-end GPUs.

## Tech Stack

- **Structure**: Vanilla HTML5
- **Styling**: Vanilla CSS (Custom properties, clamp-based fluid units)
- **Engine & Motion**: Vanilla ES6+ JavaScript, GSAP, Three.js, Matter.js
- **Deployment**: Zero-config static edge deployment optimized for Vercel

## Local Development
